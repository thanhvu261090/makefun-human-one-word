## Entry

**Bountyhunter**

He hunts bounties, jobs, and free mints around the clock — and sends his
agent out to hunt them too.

## Run

```sh
python3 main.py
```

Writes the word to `/output/entry.txt` and prints it.

## Why this word

One word, twelve letters, no explanation needed: the joke lands on its own.
